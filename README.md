# DistroLink

DistroLink is a web-based distributed URL shortening service that demonstrates core distributed computing principles in a realistic, functional application.

## Author
Muhammad Haadhee Sheeraz Mian — Reg No: 478359
Course: Parallel & Distributed Computing (PDC)

## Features
- URL Shortening
- URL Resolution / Redirect
- Load Balancing with Nginx
- Fault Tolerance
- Monitoring Page
- Horizontal Scalability

## Tech Stack
- Node.js & Express
- PostgreSQL
- Redis
- Nginx
- Docker Compose

## Getting Started
To run the project, simply use Docker Compose:
```bash
docker compose up --build
```
